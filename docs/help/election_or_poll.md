# Election or Poll?

It's the first thing BetterVoting asks you — *"Which term best describes your situation?"* — and you have to answer it before you've seen anything else.

**The short answer: it changes the words BetterVoting uses, and nothing else.** Pick whichever vocabulary sounds right for what you're running. You can change it later.

## What actually changes

One setting, one effect: the wording throughout your election.

| If you pick **Election**, you'll see | If you pick **Poll**, you'll see |
|:---|:---|
| election / elections | poll / polls |
| candidate / candidates | choice / choices |
| race / races | question / questions |
| elected office title | question title |
| ballot | response |
| vote / votes | response / responses |

So "three candidates in a race" becomes "three choices in a question," and "42 votes cast" becomes "42 responses."

The wording follows through into the invitation emails your voters receive and into the text used when you share a link, so the language stays consistent for everyone — not just on your admin screens.

## What does not change

This is the part worth being clear about, because the question arrives before you know anything about the product and it's natural to assume it's locking something in.

Choosing Poll instead of Election does **not** change:

* **the voting methods available** — STAR, Ranked Robin, Approval, RCV, and the rest are all offered either way
* **how votes are counted** — the tabulation is identical
* **who can vote** — the voter list, invitations, and authentication settings work the same
* **your security options** — every setting under Security is available either way
* **results and reports** — the same charts, the same detail, the same downloads
* **the ballot itself** — voters see the same interface, just with different labels

There is no feature that one gets and the other doesn't. It is a vocabulary setting.

{: .note }
> If a setting or feature seems to be missing, it isn't because you chose Poll — it's almost always the election's state. Most things can only be changed while your election is still a draft.

## Can I change it later?

Yes — on the **Election Settings** screen, the same place you set everything else.

The one limit is the general one: **you can only edit while your election is still in draft.** Once you finalize, the wording is locked along with everything else. If you're unsure, leave it and decide before you finalize; there's no cost to changing it several times while drafting.

## Which should I pick?

Neither is more "official" than the other — they're both the same product. Go by which words will read better to the people you're sending it to.

**Election** tends to fit when:

* you're filling a position or seat — a board, a committee, officers
* the people on the ballot are *people*, and "candidate" is the natural word
* the result is binding, or feels like it should be

**Poll** tends to fit when:

* you're choosing between options, dates, names, or ideas rather than people
* "candidate" would sound odd for what's on the ballot — *candidate: Tuesday 3pm*
* you're gathering preferences rather than filling a role

When in doubt, read the ballot question aloud both ways. *"Vote for a candidate in this race"* versus *"Choose an option for this question"* — one of them will sound wrong for what you're doing, and that's your answer.
