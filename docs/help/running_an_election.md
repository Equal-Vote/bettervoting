# Running an Election

This section is for the person creating and administering an election or poll on BetterVoting. If you were sent a voting link and just want to cast your ballot, see [For Voters](for_voters.md).

## The path from idea to results

Every BetterVoting election follows the same lifecycle, and this section is ordered to match it:

1. **Draft it.** Name it, pick a voting method, add your races and candidates, and decide who can vote and how tightly to [verify them](security_options.md). Running it on paper instead? See [Paper Ballots](paper_ballots.md). While the election is a draft you can edit everything and cast test ballots.
2. **Finalize it.** Finalizing locks the setup and clears the test ballots; the election opens on its start time, or immediately if you didn't set one. Share the voting link with your voters.
3. **Get results.** Decide whether voters see a running tally while voting is open ([Preliminary Results](preliminary_results.md)), read the results page, and know what happens on a [tie](ties.md). Want to verify the count yourself? See [Hand Count](hand_count.md).
