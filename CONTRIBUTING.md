# Contributing to BetterVoting

Thanks for your interest — BetterVoting is built and run by volunteers, and there is room for
more than code.

**Start here: <https://bettervoting.com/volunteer>.** That page covers every way to help —
development, design, writing, testing, outreach — and is the front door for getting connected
to the team.

## If you want to write code

The developer documentation lives at
**<https://docs.bettervoting.com/contributions/0_contribution_guide.html>**, including
[local setup](https://docs.bettervoting.com/contributions/developers/1_local_setup.html) and
[how to open a pull request](https://docs.bettervoting.com/contributions/developers/2_how_to_open_a_pull_request.html).

The short version:

1. Find an issue — [`good first issue`](https://github.com/Equal-Vote/bettervoting/labels/good%20first%20issue)
   is a good place to start — and say on it that you're picking it up.
2. Work on a branch in your own fork, and open the pull request against `main`.
3. Title it as a [conventional commit](https://www.conventionalcommits.org/): `fix: ...`,
   `feat: ...`, `chore: ...`, `docs: ...`.
4. In the description, say what you changed and why, add `Closes #123` so the issue closes with
   it, and include before/after screenshots for anything visual.

## Questions

Ask in the `#bettervoting` channel on the STAR Voting Slack — join via
<https://www.starvoting.us/get_involved>. Questions are welcome before you write any code; it is
much cheaper than guessing.
